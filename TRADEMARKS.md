# Trademark Guidelines

The vibecms name and any vibecms logos or visual marks identify the official project and hosted service.

You may:

- refer to the project as vibecms
- say that your project is built with, compatible with, or forked from vibecms
- use the name in non-confusing documentation and package metadata

You may not:

- present a fork or hosted instance as the official vibecms service
- use vibecms branding in a way that implies endorsement
- register confusingly similar domains, package names, or service names for a hosted competitor

If you run a modified hosted version, make it clear that it is independently operated.
