vibecms lets you give an agent a key for one site with the scopes you choose. Your agent can draft, publish, schedule, or manage the site according to that key. You can review saved versions and activity in the dashboard.

## Start here

- [Connect an agent](/docs/getting-started/connect-an-agent) and choose a key level.
- [Publish the first post](/docs/getting-started/first-publish) with a private preview and exact-version approval.
- [See scopes and tools](/docs/agent-workflows/scopes-and-tools) for all 32 MCP operations.
- [Let your agent run the site](/docs/agent-workflows/managing-the-site) with a Manage key.

## Content and distribution

- [Previews and scheduling](/docs/content/previews-and-scheduling) explains private links and timed publication.
- [URLs and redirects](/docs/content/urls-and-redirects) explains renames, archives, and deletion.
- [An agent-readable blog](/docs/content/built-for-agents) covers Markdown, feeds, and discovery files.
- [Media](/docs/content/media) and [posts and versions](/docs/content/posts-and-versions) cover the writing workflow.

## Integration surfaces

| Surface | Use it for |
| --- | --- |
| MCP | Agents and MCP-compatible clients |
| REST `/api/v1` | Direct HTTP integrations |
| `@vibecms/cli` | Shell commands and agent subprocesses |
| Dashboard | Human review, keys, settings, and editing |

The REST API and MCP tools use the same scoped authorization model. For endpoint schemas, open the [API reference](https://app.vibecms.dev/api/v1/docs).
