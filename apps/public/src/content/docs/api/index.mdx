The hosted base origin is:

```txt
https://app.vibecms.dev
```

Self-hosted installations use their API and dashboard Worker origin.

All current integration routes are under `/api/v1`. REST and MCP expose the same 32 operations for site settings and theme, voice and signup form, tags, analytics, posts and versions, private preview links, scheduling, formatting guidance, assets, and activity. See [scopes and tools](/docs/agent-workflows/scopes-and-tools) for the required scope of each operation.

## Example

```sh
curl https://app.vibecms.dev/api/v1/site \
  -H "Authorization: Bearer vc_..."
```
