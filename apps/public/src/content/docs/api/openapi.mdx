The canonical schema is generated from `packages/api-contract/src/operations.ts` and committed at `apps/api/openapi.json`.

Use the hosted schema:

- [OpenAPI 3.1 JSON](https://app.vibecms.dev/api/v1/openapi.json)
- [Interactive Scalar explorer](https://app.vibecms.dev/api/v1/docs)

The schema includes operation IDs, required bearer authentication, request and response fields, scopes in operation descriptions, and machine-readable error responses.

This page intentionally links to the live generated artifact rather than copying endpoint definitions into prose.
