# vibecms

Command-line client for the vibecms API, built for AI agents and shell workflows.

Run without installing:

```sh
npx vibecms-cli --help
```

Install globally with `npm i -g vibecms-cli` to get the `vibecms` command.

Connect and list posts as JSON:

```sh
vibecms login --token vc_...
vibecms posts list --json
```

Documentation: [vibecms CLI guide](https://vibecms.dev/docs/cli).
